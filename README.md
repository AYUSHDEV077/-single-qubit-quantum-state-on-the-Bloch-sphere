#  Interactive Quantum Computing Simulator

An interactive, web-based quantum computing simulator built with Python, Streamlit, and Qiskit. This application provides a highly visual environment to explore fundamental quantum mechanics, bridging the gap between abstract quantum algorithms and intuitive visual understanding.

##  Features

*   **Real-time 3D Bloch Sphere:** Visualize single-qubit states dynamically. As gates are applied, the state vector updates instantly on an interactive, rotatable 3D Bloch sphere built with Plotly.
*   **Fundamental Quantum Gates:** Apply standard quantum logic operations including the Hadamard (H) gate and Pauli matrices (X, Y, Z) to observe phase shifts and bit flips.
*   **Bell State & Entanglement Simulator:** Explore two-qubit systems by combining Hadamard and CNOT gates to generate all four fundamental Bell states.
*   **State Analysis & Metrics:** Automatically calculate and display state vectors, probability amplitudes, measurement probabilities (via interactive histograms), and entanglement entropy.
*   **Interactive Measurement:** Simulate quantum measurements with adjustable shot counts to compare empirical distributions against exact theoretical probabilities.

##  Technologies Used

*   **Python:** Core programming language.
*   **Streamlit:** Web framework for the interactive UI.
*   **Qiskit (IBM):** Quantum circuit construction and state vector simulation.
*   **Plotly:** Interactive 3D rendering and histogram generation.
*   **NumPy & Pandas:** Mathematical operations and data formatting.
